## 1. Moving the project with snapshot_changes.py
**Q:** I copied `tools/snapshot_changes.py` to collect what to move. I already moved the models (very big).

**A:** It only copies files that are new or changed since a snapshot, so the first move uses an **empty baseline**:
```bat
python tools\snapshot_changes.py snapshot --name empty --exclude "*"
python tools\snapshot_changes.py copy D:\hkc\transfer\hkc_1126_code\igcode --snapshot empty --exclude models --exclude pkgs/inventory --exclude outputs --exclude bench_results --exclude cmds/logs --update
```
Result: 480 files, 487 MB, no model. The user ran it, and the checksum verify of the copy gave **477 OK**.

If the model isn't at `<project>\models\Z-Image-Turbo` on the GPU machine: `set ZIMAGE_MODEL_PATH=<model folder>`.

**Q:** Put a guide for snapshots in `cmds`.
**A:** `cmds/11_snapshot_updates.md`. Routine update:
```bat
python cmds\scripts\bundle_checksums.py create
python tools\snapshot_changes.py changes
python tools\snapshot_changes.py copy D:\hkc\transfer\hkc_MMDD_update\igcode --dry-run
python tools\snapshot_changes.py copy D:\hkc\transfer\hkc_MMDD_update\igcode --update
```
⚠️ Don't pass `--exclude` on routine updates. It **replaces** the stored excludes, including `models`.

**Q:** I'll modify things later and track changes with snapshots.

## 3. Is the transfer in sync with the current project?
| Question | Command | Good result |
|---|---|---|
| Did I send everything I changed? (this PC) | `python tools\snapshot_changes.py changes` | `0 new, 0 changed, 0 deleted` |
| Is a full copy intact? (copy or GPU machine) | `python <copy>\cmds\scripts\bundle_checksums.py verify` (on the GPU machine add `--target 5090` or `--target h200`) | `N OK, 0 missing, 0 corrupt` |
| File-by-file diff of a full copy vs the project (this PC) | `robocopy D:\hkc\image_llm <copy> /E /L /NJH /NJS /NDL /NP /XD models .git .snapshots __pycache__ _changes /XF SHA256SUMS.txt` | no output |

Run `bundle_checksums.py verify` only on full copies, not on update folders, which hold only the changed files.
